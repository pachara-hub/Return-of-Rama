# Return of Rama — 3D Epic

A browser-based Ramakien-inspired action game built with WebGL 2.

## Play online

https://pachara-hub.github.io/Return-of-Rama/

## Controls

- Move: WASD or arrow keys
- Skills: Q, E, R or 1, 2, 3
- Pause: P or Escape
- Touch controls are available on mobile browsers.

## Technology

- Custom WebGL 2 renderer
- Procedural 3D characters and stage architecture
- Embedded or local art/audio assets
- GitHub Actions + GitHub Pages deployment

The workflow in `.github/workflows/pages.yml` deploys the static game when commits are pushed to `main`.
